## Message

Une IA générative compose une réponse nouvelle à partir d’une instruction, d’un contexte et de connaissances apprises. Elle est puissante, mais elle peut se tromper.

## Copy canonique

- `CONTEXTE + INSTRUCTION + CONNAISSANCES APPRISES → RÉPONSE`.
- Un LLM a appris les relations entre mots, concepts, intentions, structures et raisonnements.
- Il ne faut pas le présenter comme une base de données contenant toutes les réponses.
- `IA = puissance + contexte + outils + contrôle`.
