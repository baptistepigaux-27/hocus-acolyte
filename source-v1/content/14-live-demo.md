## Message

À partir d’une phrase métier, on peut faire émerger le contexte, les sources, la méthode, l’issue, le prototype et la validation.

## Copy canonique

> J’ai une entreprise de 50 personnes et je voudrais identifier trois usages pertinents de l’IA.

- GPT : cadrer.
- Web / documents : rechercher.
- Obsidian : retrouver.
- GitHub : formaliser.
- Codex : construire.
- Humain : tester, commenter, décider.

## Atomes visuels

- cinq scènes reliées ;
- question persistante en haut ;
- schéma final humain → IA → mémoire / outils / données → action.

## Réemploi webapp

Parcours guidé de bout en bout, avec branchement vers chaque outil et chaque preuve.
