## Message

Le modèle raisonne ; les outils lui donnent accès à des documents, données, logiciels et actions.

## Copy canonique

- Document : PDF → risques et points à vérifier.
- Données : CSV → segments atypiques.
- Recherche : sources → acteurs d’un marché.
- Création : analyse → présentation.
- Action : décision → issue GitHub.

## Atomes visuels

- IA au centre et outils autour ;
- cinq cartes entrée / sortie ;
- distinction observer / produire / agir.
