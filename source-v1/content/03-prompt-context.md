## Message

Un bon résultat dépend de la situation de travail complète : objectif, contexte, données, contraintes, outils et historique.

## Copy canonique

- `Bonne question → bonne réponse` est un modèle trop pauvre.
- `Objectif + contexte + données + contraintes + outils + historique → IA → résultat`.
- Cas fil rouge : préparer un rendez-vous client, puis le compte-rendre et les prochaines actions.

## Atomes visuels

- avant / après ;
- fiche contexte ;
- boucle de réunion en cinq étapes.

## Réemploi webapp

Context builder : ajouter ou retirer une pièce de contexte et comparer le résultat attendu.
