## Message

Un système de travail utile organise les étapes et concentre l’attention humaine sur les décisions conséquentes.

## Copy canonique

`Idée → Issue → Branche → Développement → Tests → Pull Request → Préproduction → Validation humaine → Production`.

- Les étapes automatiques sont reproductibles.
- Les preuves permettent de revoir le résultat.
- Les gates humaines restent obligatoires pour la production, les changements majeurs et les accès sensibles.
