## Message

Un besoin métier peut passer par GPT, Obsidian, GitHub et Codex avant de devenir une application testable.

## Copy canonique

- Northstar TEN : DCE et données de marchés publics → analyse → score explicable → go / review / no-go.
- Les faits, les inférences et les scores restent distincts.
- Le cycle traçable est `SPEC → ISSUE → CODE → TESTS → PR → STAGING → APPLICATION`.
- L’humain valide le résultat avant la promotion.
