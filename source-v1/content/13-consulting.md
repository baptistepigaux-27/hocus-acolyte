## Message

Une mission peut produire une recommandation, un prototype, une application et une boucle de mesure, selon le besoin.

## Copy canonique

- 50 fichiers Excel + PDF + une question métier peuvent devenir un pipeline utile.
- Le résultat peut être un notebook, un script, une analyse, un dashboard, un agent ou une mini-webapp.
- Conseil classique : analyse → PowerPoint.
- Conseil augmenté : analyse → prototype → tests → application → mesure → amélioration.

## Atomes visuels

- pipeline de transformation ;
- avant / après ;
- sortie graduée selon la valeur prouvée.

## Réemploi webapp

Choix du format de sortie et visualisation du passage recommandation → action.
