## Message

GitHub rend le travail opérationnel traçable : besoin, code, historique, tests, revue et version testable.

## Copy canonique

- Issue : ce qui doit être fait et comment le valider.
- Branche : espace isolé pour l’évolution.
- Commit : étape enregistrée.
- Pull Request : proposition à relire.
- Tests / staging : preuves et version testable avant production.

## Atomes visuels

- fiche d’évolution ;
- historique avant / après ;
- chaîne issue → code → tests → PR.

## Réemploi webapp

Explorateur d’artefacts d’une évolution, du besoin à la version déployée en staging.
