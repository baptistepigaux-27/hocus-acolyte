## Message

Un agent est une IA à laquelle on donne un objectif, des outils et une autonomie bornée pour réaliser plusieurs étapes.

## Copy canonique

- Chatbot : question → réponse.
- Assistant : aide l’utilisateur dans une tâche.
- Agent : objectif → plan → outil → observation → nouvelle décision.
- L’utilisateur ne décrit pas chaque étape, mais les règles et les limites restent explicites.
