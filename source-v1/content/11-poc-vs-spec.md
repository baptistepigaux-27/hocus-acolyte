## Message

Le niveau d’investissement doit suivre l’incertitude : formaliser quand le besoin est compris, tester quand la valeur ou la faisabilité reste incertaine.

## Copy canonique

- Spec Driven : vision → specs → produit.
- POC Driven : question → prototype → données réelles → observation → value gate → go / no-go.
- Northstar TEN illustre la formalisation progressive.
- Sybil illustre l’apprentissage par POC sur des données publiques/fixtures.

## Atomes visuels

- deux chemins ;
- curseur « incertitude de conception / incertitude de valeur » ;
- gate GO / NO-GO.
